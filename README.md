# Calculator 

A simple calculator app built in Flutter/Dart — created as a hands-on learning project to break out of tutorial hell and actually build something independently.

## 🎯 Why this project

Instead of following along with another tutorial, this was built by figuring things out directly — understanding Dart syntax, Flutter widgets, and state management through trial and error rather than copy-pasting.
